# Novagram Voice Changer Kit

Real-time voice changer SDK shared by the Novagram iOS and macOS Telegram clients (and, through a C API, Android):
voice presets for voice messages and calls — man, woman, child, chipmunk, robot, alien, monster, echo, cave and more.

Work in progress. v1 is a port of the Novagram Android voice changer; v2 adds pitch-aware presets
(the shift follows the speaker's own pitch), a higher-quality pitch/formant engine and auto-tune.
